# 운영 안내

이 문서는 tokmo-v3를 설치한 뒤 운영할 때 알아야 할 경계를 정리합니다. 알림과 제안은 판단 자료이며, 매매 결정은 설치한 사람에게 있습니다.

## 스케줄

`ops/cron/crontab.example`(Docker에서는 `docker/crontab`)의 주기입니다. 시각은 모두 Asia/Seoul 기준입니다.

| 주기 | 잡 | 비고 |
|---|---|---|
| 1분 | 펄스 | 보유·체결, 스톡봇 대화, 뉴스 발송. 토큰은 매분 0-5초에만 읽습니다 |
| 5분 | 캐던스, 후속 점검 | |
| 15분 | 뉴스 그룹 a·b·c | 그룹마다 5분씩 어긋나게 실행됩니다 |
| 1분 (스스로 간격 조절) | fast primary, 뉴스 판단 워커 | 워커는 한 번 실행되면 최대 약 8분 동안 동작합니다 |
| 30분 | OpenDART, SEC | |
| 30분 | 제품 게이트 heartbeat | 쿼터 스냅샷을 갱신합니다. 측정이 아니라 생존 기록입니다 |
| 평일 08:40 | 회전 정산 | |
| 평일 10:15 | 회전 분석과 제안 발송 | 분석은 10:40까지 끝납니다 |
| 평일 10:40-11:10, 10분마다 | 회전 보조 마감 | 제안 승인 창은 알림 발송 뒤 30분(최대 11:10)이며, 마감 5분 전에 한 번 예고합니다 |
| 평일 08-21시, 5분마다 | 회전 결과 평가 | 결과 기록만 하며 모델은 부르지 않습니다 |
| 평일 08-16시, 1분마다 | 모의투자 step | 판단은 10:05와 13:30에만 하고, 판단이 끝날 때마다 결과 요약을 한 번 보냅니다 |

## 실주문 조건

회전매매만 실계좌로 주문합니다. 모의투자는 원장에만 기록합니다.

| 조건 | 결과 |
|---|---|
| `var/state/hyundai-rotation/live.flag`가 있고 토스 주문 권한이 있습니다 | 실주문을 냅니다 |
| `live.flag`가 없습니다 | 드라이런입니다. 분석과 제안은 하지만 주문은 보내지 않습니다 |
| `live.flag`가 심링크이거나 group·other 권한이 있습니다 | 플래그가 없는 것으로 처리합니다 |
| `tools/run_hyundai_rotation_daily.py`에 `--live`를 줍니다 | 플래그 파일과 같은 효과입니다 |

처음에는 `live.flag` 없이 드라이런으로 며칠 운영해 보시는 것을 권장합니다. `tools/rotation_rehearsal.py`는 별도 작업 디렉터리에서 월요일 하루 동안 주문 주기를 시험합니다. 시험 주문이 모두 닫혔다고 확인될 때만 그날 저녁에 `live.flag`를 만들고, 그 밖에는 운영 디렉터리를 건드리지 않습니다.

## 모델 호출과 쿼터

- 모델은 `~/.hermes/MODEL_ROUTING_STATE.md` 목록에 있는 정확한 id만 호출합니다.
- 호출 전에 CALL 영수증을, 호출 후에 RESULT 영수증을 남깁니다. 전송 직전에 한 번 더 검사하며, 영수증을 쓰지 못하면 호출하지 않습니다.
- 뉴스 판단만 전환 순서를 지원합니다. 모의투자와 회전 진입은 모델 하나로 동작하고, 후속 점검은 모듈 설정을 따릅니다.
- 배포판의 쿼터 스냅샷은 실제 측정값이 아닙니다. 한도 소진은 모델 오류로 드러나며, 뉴스 판단은 전환 순서로 처리하고 나머지 모듈은 그 실행이 실패합니다.
- 코드를 갱신하면 승인 파일의 해시가 맞지 않아 호출이 멈춥니다. `tools/install_product_gate.py issue --reissue`로 다시 발급합니다.

> **중요:** `ops/product-gate/OPERATING_CONTRACT.md`는 승인 파일이 sha256으로 고정하는 운영 계약입니다. 한 글자라도 바꾸면 발급한 승인 파일이 모두 무효가 됩니다(`AUTHORITY_DRIFT`).

## 펄스 일시정지

펄스는 최근 5분 동안의 외부 호출 수가 상한을 넘으면 `<runtime_root>/runtime/pulse-paused.marker` 파일을 만들고 멈춥니다. 이때 **시스템 알림은 보내지 않습니다.** 영수증이나 표식 파일을 직접 확인해야 합니다. 원인을 확인하고 표식을 지우는 절차는 [펄스 일시정지 런북](pulse-g2-shadow-runbook.md)에 있습니다.

## 데이터와 개인정보

- 상태와 기록은 모두 `var/` 아래에 있으며 git에서 제외됩니다. 자격증명은 `.secrets/`, `.env.toss`, `.env.kis`에 있습니다.
- 저장소 파일은 0600으로 만들고 심링크는 거부합니다. 자격증명 파일이 0600 일반 파일이 아니면 해당 어댑터가 읽지 않습니다.
- 알림과 영수증에는 자격증명, 계좌번호, 대화 원문을 쓰지 않습니다.
- 관심 종목(`watchlists/`)에는 종목 코드와 추적 의도만 적습니다. 수량, 평단, 계좌, 현재가는 넣을 수 없습니다. 실제 보유 여부는 토스 보유 데이터만 기준으로 삼습니다.
- 배포판에는 원작자의 플레이북, 계좌, 대화, 평가 이력이 없습니다. 제외하고 바꾼 내역은 `DIST-EXPORT-REPORT.json`에 있습니다.

알려진 한계는 다음과 같습니다.

- 회전매매의 미국 시장은 구조만 있고 동작하지 않습니다.
- 모델 전환 순서는 뉴스 판단에만 있습니다.
- 배포판의 쿼터 스냅샷은 측정값이 아닌 heartbeat입니다.
- 원작자 환경을 전제로 한 테스트 일부는 다른 환경에서 실패할 수 있습니다.
